# Projeto Java - Prática com Git

Projeto simples em Java criado para praticar Git e controle de versionamento.

## Sobre o projeto

O programa exibe algumas informações básicas no terminal:

- Uma mensagem de boas-vindas;
- O nome de uma pessoa;
- A idade da pessoa.

O objetivo principal deste projeto não é desenvolver uma aplicação complexa, mas utilizar o código como base para praticar os principais comandos do Git.

## Tecnologias utilizadas

- Java
- Git
